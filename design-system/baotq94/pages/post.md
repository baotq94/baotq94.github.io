# Article layout

This page overrides the global 720px content limit for article routes.

- Let the article shell fill the viewport, with side gutters of `clamp(1rem, 3vw, 4rem)`.
- Keep the title, metadata, paragraphs, lists, and section headings centered within 720px.
- Let tables, code blocks, images, and diagrams use the available article width.
- Keep horizontal scrolling inside tables, code blocks, and wide diagrams only when needed.
- Keep the default narrow shell for other routes.
